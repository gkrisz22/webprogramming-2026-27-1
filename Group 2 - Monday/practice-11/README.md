# PHP 3 - Todos in a database

Do this before class:

1. Open a terminal in this folder and run `php check.php`. The last line must say **Ready for PHP 3**.
2. If it says **Not ready**, run `php fix.php`, then `php check.php` again.
3. Install the VS Code extensions **SQLite3 Editor** (yy0931) and **SQLite Viewer** (Florian Klampfer).
4. Start the server with `php -S localhost:8080` and open `http://localhost:8080/setup.php`. It creates `todos.db`.

`index.php` is the finished todo page from PHP 2. The task page walks through the changes step by step.
Open `setup.php` again at any time to reset the database to the five starting todos.
